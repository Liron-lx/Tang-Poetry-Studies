> - 《唐代侠义诗可视化 · 视觉规范》（项目根目录 `唐代侠义诗可视化-视觉规范.md`）

## 一、总体判断：两套视觉体系并存，规范零落地

项目中同时存在"旧四页 + 备用页"与"新页面"两个时代的产物，加上规范文档本身，**三份资产各说各话**：

| 维度 | 旧页面（interactive / poetry-emotion / word-association / keyword-river / circular_sankey） | 新页面（xiayi-scroll / geography-tang-overlay） |
|---|---|---|
| 配色 | 自定莫兰迪色（`#A8B5A0`、`#8B7D6B`、`#6B5B73`、`#F4D78B`…） | 自定义令牌（`#F2ECE1`、`#A9D8D1`、`#273C3A`…），与规范接近但不同 |
| 字体 | Arial + MiSans（MiSans 从未真正引入，实际回落系统字体） | Noto Serif SC + 系统无衬线 |
| 背景 | 纯白 `#fff`（规范明确禁止） | 宣纸暖白 + `feTurbulence` 颗粒 |
| 布局 | 1440px 固定宽、全绝对定位（Figma 导出稿痕迹） | 流式 + viewBox，有响应式意识 |

**关键事实**：《视觉规范》色板 13 个色值（宣纸白 `#F5F2EA`、石绿 `#8FAE8B`、天水碧 `#5BA4A4`、黛蓝 `#3D5A6C`、朱砂 `#B04A3A` 等）在全部 HTML/JS/CSS 中出现次数为 **0**。规范字体（Ma Shan Zheng / Noto Serif SC / EB Garamond）仅 `xiayi-scroll.html` 与 `geography-tang-overlay.html` 两个新页使用。唯一的共享样式 `assets/css/common.css` 仍是 `#171717` / `#fbeeee` 等与规范无关的变量。

## 二、逐页问题与改造方向

### 1. 侠踪天下（`interactive.html` + `sketch.js`，p5.js 地图）——编码自相矛盾，最需要重做

- **热力层与频次层脱节**：`calculateHeatValue()` 注释明写"每个地点的影响范围和强度都相同，不考虑频次"。灰度点阵热力表达"地点密度"，三角形高度表达"频次"，两套信息互相稀释，违反手法总结"一形多义"原则（一个图形单元承载 3–5 个维度）。
- 五色分类（京城红棕 / 边塞深蓝 / 关隘暖棕 / 内陆青蓝 / 其他青绿）平起平坐，无视觉焦点，违反规范"对比色只做强调"。
- **改造方向**：按规范路线 C（点线解构型）做**半调网点山**——点大小编码频次（规范 §5.4 已有此映射）；类型收敛为朱砂/黛蓝二色区分"边塞 vs 内地"，五色细节退入 tooltip；补"如何阅读此图"说明区（手法总结 §6）。
- 可保留：图例点击缩放 1.5 倍的交互。

### 2. 剑影诗心（`poetry-emotion.html`，词频页）——力导向图用错了地方

- 词频数据无天然关系结构，却用 ECharts force-directed graph：节点位置不编码任何信息；边是人为构造的"同类别随机连一条、透明度 0.05"的伪关系。频次、分类两个维度被浪费。
- 8 个类别色违反规范"单画面色相 ≤3"。
- 数据硬编码在 HTML 内（含 `"侠客  "` 带尾空格的脏数据，靠 `.trim()` 补救），应移入 `data/` 下 CSV。
- **改造方向**：手法总结 §2 隐喻式图形的最佳战场——仿案例 6/12 做**花瓣/放射线束**（每个高频意象一朵花，花瓣/线束长度=频次，花色=类别），或仿案例 12 按频次分档；类别色按规范数据序列（石绿→天水碧→黛蓝→赭石→藤黄）收敛，朱砂只给最高值"侠客"（54 次）。

### 3. 侠骨柔情（`word-association.html`，情感矩阵）——编码规则反直觉

- 诗 × 8 情感维度的散点矩阵方向本身可行（近案例 10 矩阵散布），但：
  - 气泡大小与透明度编码**同一个值**（冗余双编码）；
  - 透明度规则为"值越大越透明"（9 分→0.2 不透明度，0 分→1.0 全不透明且仍画点）——最强情感最不可见，0 值反而有实心点，与阅读直觉相反；
  - x 轴 100 个"作者-诗名"标签 6px 竖排，事实不可读。
- **改造方向**：0 值不画点；透明度改为值越大越实；x 轴收敛为可读的诗人分组，或仿案例 9（红楼梦）纺锤图竖向排列、宽度编码频次。
- **重复文件**：`可行情感1.html` 与本页数据重复，代码中残留"这里需要复制可行情感1.html第17行到第1245行"的注释，应合并为一页。

### 4. 侠韵流殇（`keyword-river.html`）+ `circular_sankey.html`——同题双页，留一弃一

- 两页做同一份数据（作者—聚类关系，`data/poetry_with_detailed_clusters_sankey.csv`），README 自注弦图为"备用页面"。
- `morandiColors` 按字符串哈希取色，同一作者跨刷新颜色不稳定。
- **改造方向**：保留 keyword-river（河流图方向符合手法总结 §3 案例 13/14 的流带思路），归档 circular_sankey；配色换规范令牌。

### 5. 首页（`index.html`）——入口页，还不是叙事页

- 四个入口卡片平铺并列，无主线。建议按手法总结 §6"主图 + 辅图矩阵"：以《侠义长卷》为主视觉，四个专题页退为辅图。
- 工程残留：`<title>数字人文测试</title>`、meta "Web site created using create-react-app"；`poetry-emotion.html`、`word-association.html`、`keyword-river.html` 三页标题同为"数字人文交互页面"。

## 三、跨页共性问题（按优先级）

1. **规范零落地**：将《视觉规范》第九节 CSS 变量真正写入 `assets/css/common.css`；旧页五色/八色调色板全部替换；纯白背景换宣纸白 `#F5F2EA`。
2. **字体链断裂**：24 处 `Arial, sans-serif`、8 处 `MiSans`（未引入字体文件）；规范要求标题 Ma Shan Zheng / Noto Serif SC、西文标签 EB Garamond——目前仅 2 个新页做到。
3. **肌理缺失**：规范要求颗粒/雾化/层叠剪影"至少用其一"；旧页全部平涂 + 线性渐变，仅 xiayi-scroll 使用 `feTurbulence` 噪点。
4. **插画资产闲置**：`高频诗人画像/`（工作区上层目录）中李白、杜甫、王维、高适、骆宾王的全身图/形象图未在任何数据页使用——手法总结 §7 指出插画负责"情感锚点"，词频页/情感页边缘正是其位置。
5. **重复与硬编码**：3 个地图页（interactive / geography / geography-tang-overlay）、2 个情感页（word-association / 可行情感1）、2 个关系页（keyword-river / circular_sankey）、2 个词频页（poetry-emotion / 词频可视化）并存；词频与情感数据硬编码进 HTML 而非读 `data/`；库依赖全走 CDN（README 已自知，离线部署需本地化）。
6. **响应式缺失**：旧页全部 1440px 固定宽绝对定位，无移动端适配。

## 四、值得保留并发扬的基础

- `data/poem_dates.csv` 的作品级系年审计与证据分层（observed / inferred / duplicate / unavailable）非常扎实，是项目最独特的资产。
- `xiayi-scroll.html`（《侠义长卷》）将不确定性可视化为"待考雾域"，配合颗粒肌理、克制配色、证据层级图例，是全项目最符合手法总结精神的一页（密度即信息、一形多义、克制即豪气）。**应确立为全项目视觉基准**，其视觉语言文档见 `docs/visual-language-xiayi-scroll.md`。
- 旧页的交互骨架（图例联动、tooltip、诗歌锁定高亮）可在新视觉体系下保留。

## 五、建议的改造顺序

1. 设计令牌落地：规范色板/字体写入 `common.css`，全站引用（含导航栏 Arial → 规范字体）。
2. 试点改造：以词频页（poetry-emotion）为样板，重做为花瓣/放射线束式图形 + 规范配色 + 颗粒肌理，验证旧页改造路径。
3. 地图页重做：半调网点山方案，解决热力/频次双编码冲突。
4. 情感矩阵修正：0 值不画点、透明度规则反转、x 轴收敛；合并 `可行情感1.html`。
5. 页面收敛：关系页留 keyword-river；地图三页明确主备；清理标题/meta 残留。
6. 叙事整合：首页改为"长卷主视觉 + 四专题辅图"结构；诗人画像作为情感锚点引入。
