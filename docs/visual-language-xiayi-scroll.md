# 《侠义长卷》视觉语言

## 定位

《侠义长卷：一百首唐代咏侠诗的五脉流变》是本项目的竖版主视觉。它不是一张将数据隐藏在山水中的插画，而是一张让时间、作品密度、主题与系年不确定性共同生长为山水的诗性信息图。

核心意象为“唐诗不是被钉在时间轴上，而是在唐代山河与人世流动中浮现”。

## 固定风格原则

- 以暖白宣纸为底，保留大面积呼吸感，不使用满屏装饰。
- 以低饱和青绿、灰蓝和墨黑为主，浅赭石与黯金只用于少量强调。
- 山势、云气、水波服务于信息结构；每一处装饰都必须对应时间、主题、密度或不确定性。
- 真实系年使用清晰、较实的节点；活动期或生卒年推定使用半透明、颗粒化、较轻的节点；无法定位的记录停留在“待考雾域”，不伪造年份。
- 文字采用宋体/明朝体式标题和克制的无衬线数据注释；避免热闹的武侠商业海报、霓虹色和游戏概念图语言。
- 允许细线、等高线、水波线和淡雾，但避免高对比的粗网格或饼图式分类图例。

## 《侠义长卷》的信息映射

| 数据 | 视觉语义 |
| --- | --- |
| `timeline_year` | 纵卷中的时间高度 |
| 五个 `cluster` | 五条色相接近但走势不同的“脉” |
| `timeline_status=observed_*` | 清晰实点与短线 |
| `timeline_status=inferred_*` | 低透明度雾点与颗粒簇 |
| `timeline_status=duplicate_inherited` | 轻小的伴生点 |
| `timeline_status=unavailable` | 末端“待考雾域”的无年份诗作 |
| 同一时期作品数 | 水波/山势的局部起伏 |

## 版式结构

页面是可滚动的长卷：题记与图例在顶部，五脉在中部展开，待考雾域置于长卷末端。各脉并不做传统等宽栏目，而是以缓慢迁移的横向位置和半透明带状水流形成互相呼应的行旅路径。鼠标悬停或键盘聚焦节点时显示作者、篇名、主题、年份/推定说明。

## 后续页面一致性

其他可视化页可沿用同一底色、字形、节点证据层级和低饱和主题色；但只有主长卷使用完整山水叙事，避免每一页都重复山水插画。
