# 《诗风侠影》Figma 分页重构设计

## 目标

将 Figma Section「唐代侠义诗网页-0818修改」落实为可访问的静态网站：按“序、时、地、人、心、存”推进叙事，保留现有研究数据的完整性；桌面端悬浮预览、点击锁定，移动端仅以点击完成选择。

## 范围与路由

| Figma 状态 | 网站入口 | 交互边界 |
| --- | --- | --- |
| `00`、`01-1` 至 `01-5` | `index.html` | 片头、书本序章、展卷、五章目录 |
| `02` | `xiayi-scroll.html` | 时间河流与时代叙事 |
| `03-1`、`03-2` | `interactive.html` | 同一页面的默认地图与地点展开状态 |
| `04`、`04-2` | `poets.html` | 同一页面的诗人总览与详情状态 |
| `05-1`、`05-2` | `emotions.html` | “两个世界”、人物/词象筛选与图表状态 |
| `06` | `keyword-river.html` | 汇总关系图、方法尾注与收卷 |

不为 `03-2` 或 `04-2` 创建独立 URL；浏览器后退、关闭详情和取消筛选都应回到对应页面的默认状态。

## 共同交互规则

- 桌面端的悬浮仅显示预览；点击才锁定章节展开、地点、诗人或词象筛选。
- 移动端不依赖悬浮，使用点击完成同一选择；目录和卡片均保留键盘可达的按钮语义。
- 尊重 `prefers-reduced-motion`：书本翻页、视差和淡入可直接展示最终状态。
- 页面顶部维持“序、时、地、人、心、存”导航；当前章节明确标记。
- 使用 Figma 的墨色、宣纸、砂岩和朱砂视觉体系，但红字只作为设计说明，不进入面向读者的页面内容。

## 数据与内容约束

- 保持 `data/` 中 100 首诗歌、76 个地点和现有 CSV/JSON 的完整来源口径；不可为视觉效果抽样或改写原始数据。
- 地点页从 `地方名称及经纬度.csv` 动态读取完整地点集；低频地点可以更小或更淡，但仍须显示。
- 情感与词频页继续使用 `emotion_scores.csv` 与 `word_frequency.csv`，并依据 Figma 的十二种物件分类替换不再适用的旧文案。
- 现有 `scripts/validate_project.py` 是数据基线；`scripts/smoke_test.py` 的根页清单须与 README 中的正式入口同步，归档页不得作为正式路径测试。

## 分页交付顺序

1. 修正基线测试清单并建立共用样式、导航和无障碍交互工具。
2. 序章：片头、书本状态、展卷、长卷与目录。
3. 时：时间河流。
4. 地：地图默认/展开状态。
5. 人：诗人总览/详情状态。
6. 心：两个世界和人物/词象筛选。
7. 存：汇总、方法尾注、深色收卷。
8. 逐页响应式、键盘、动效偏好和全站部署检查。

每一页完成后先提供本地预览与验证结果；获得确认后才开始下一页。

## 验收标准

- `npm run validate` 通过。
- `npm test` 只检查当前正式页面并可在本地静态服务器上通过。
- 每个页面在桌面和窄屏下没有横向溢出，核心操作可以用鼠标、触摸或键盘完成。
- 实现与已确认的 Figma 状态一致：`03-1 → 03-2` 是地点展开，`04 → 04-2` 是人物详情，第五章为“悬浮预览、点击锁定；移动端仅点击”。
