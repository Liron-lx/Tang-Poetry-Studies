# 《诗风侠影》叙事架构设计（2026-08-16 定稿方向）

骨架：六幕章回 ｜ 开场：考据悬念 ｜ 观点：双轨视角（第四幕）
视觉语言：沿用《侠义长卷》宣纸青绿体系（docs/visual-language-xiayi-scroll.md）

---

## 整体设计逻辑

- **一条叙事线**：侠义诗是什么 → 何时兴起 → 发生何地 → 何人书写 → 心藏何物 → 如何流传
- **一个文学观点**（双轨）：侠客是诗人的自我投射——侠气是想象，孤愤是现实。不在开场说破，让用户在第四幕自己看出来
- **一个贯穿元素**：印章。题材标签是章、系年落款是章、每幕结尾盖一枚幕章（时/地/人/心/存），终幕盖"侠"字总章。收集感不靠游戏化，靠文人式的"展卷钤印"
- **每幕固定节奏**：幕题（回目式命名）→ 核心图 → 一段解读文字 → 幕尾钩子引向下一幕

## 全局交互规范

- 顶部导航：单字章回【序·时·地·人·心·存】，悬停显示全名（如"心 → 侠心何似"）
- 主交互只有三种：滚动推进叙事、悬停查看详情、点击展开/过滤。不做炫技控件
- 跨页一致性：同一首诗在任何页面hover，都显示相同的信息卡（诗名/作者/系年/题材/情感剖面）
- 转场：幕间以淡墨晕染过渡，不用硬切

## 序 · 何谓侠（首页，重写 index.html）

**任务**：30 秒抓住人 + 交代语料 + 给出目录。

**首屏 · 考据悬念**：
一首诗悬浮在淡雾中（选语料中未定年的作品，如张易之《出塞》），只有一句问话：
> "这首侠客诗写于哪一年？没有人知道。"

用户点击"循证而往"，跟随三步证据链（年谱记载 → 编年版本 → 事件锚点），诗最终没有落定，缓缓沉入雾中——字幕："100 首里，有 70 首至今无法系年。我们把这份不确定也画了出来。"

**第二屏 · 事实带**：100 首诗 / 53 位诗人 / 76 个地点 / 5 类侠义主题，四个数字竖排钤印式排布。

**第三屏 · 回目**：六幕章回竖排展开，点击进入各幕。

**落点文案**："侠气从何时起，到何处去——展卷。"

## 第一幕 · 侠从何来（时）｜ xiayi-scroll.html 升级

**核心问题**：侠义诗在哪个时代最盛？

**内容**：现有侠义长卷优化版——五条主题河流沿时间纵轴流淌，每首诗一个节点：
- 确证系年 = 实点；推定 = 雾点；未定年 = 沉入卷末"待考雾域"
- 新增：初唐/盛唐/中唐/晚唐分期标尺 + 755 安史之乱一道朱砂细线
- 交互：hover 节点出信息卡；点击五脉图例单独高亮一脉；滚到雾域时浮现说明文字

**幕尾钩子**："侠踪既现于时间，亦行于山河——他们仗剑去了哪里？→"

## 第二幕 · 侠行何处（地）｜ interactive.html 升级

**核心问题**：侠客在什么地方出现？

**内容**：双层结构——
- 艺术层：保留现有三角山峰地图（唐疆域底图加深）
- 准确层（新增）：Top 10 地点横向条形图，长安 50 次的压倒性用长度说清
- 地点着色按现有"类型说明"：京城 / 边塞 / 关隘 / 内陆城市
- 交互：hover 地点出频次+类型；点击长安、幽州、洛阳等关键地点，侧栏浮出相关诗句；顶部一个克制的分段切换【地图｜排行】，两视图共用一个数据

**幕尾钩子**："长安与边塞之间，写诗的是谁？→"

## 第三幕 · 侠者何人（人）｜ 新页面

**核心问题**：谁在写侠？

**内容**：五人全身图群像，一人一境（李白/杜甫/王维/高适/骆宾王）：
- 全身图为视觉主体；每首诗一块竖排诗牌，呈现最侠气的一句
- 诗牌角上：题材印章 + 系年落款小字
- 人物身后场景剪影编码其世界（高适=塞外孤城 / 王维=终南山 / 李白=江湖舟楫 / 骆宾王=帝京 / 杜甫=乱世烽烟）
- 交互：hover 诗牌展开全诗摘录；点击诗牌"翻牌"，背面是该诗的系年证据（呼应序章考据主题）；点击诗人名，其全部诗牌高亮、其余淡去

**幕尾钩子**："他们写下这些句子时，心里装的是什么？→"

## 第四幕 · 侠心何似（心）｜ poetry-emotion + word-association 合并重做

**核心问题**：侠的内心世界是什么？——本幕给出全站的核心观点。

**双轨不以控件呈现，以"对位排版"呈现**（不用开关，静态结构即观点）：

1. **两个世界**：八维情感分两栏对置陈列——
   左栏「侠客的世界」：壮怀逸兴 / 同袍之谊 / 家国义愤 / 死生超然
   右栏「诗人的内心」：功名热望 / 功名幻灭 / 孤愤悲慨 / 苍茫孤寂
   每栏下接该四维在五类主题上的分布（点线图）

2. **投射散点图**（本幕核心图）：每首诗一个墨点，x = 侠客侧均分，y = 诗人侧均分。分布自然呈现：整体偏侠气，但杜甫、高适的诗沉在诗人侧——"边塞是想象，孤愤是现实"。
   - 交互：hover 墨点，两栏对应维度条同时亮起，显示这首诗的"两副面孔"；点击顶部诗人名，过滤高亮其所有诗

3. **词频双层**：每类 Top 8 棒棒糖图（准确层）+ 词语星群（艺术层，保留现有气质）

**幕尾钩子**："一百首诗，五种侠气，最终流向何处？→"
